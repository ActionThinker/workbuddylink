政务场景使用 AI 前，请先读这三条红线 强制首读
  1. 涉密材料一律不上传：标注「秘密 / 机密 / 绝密」及内部定为涉密的文件数据，绝不输入任何公有云 AI 工具，物理隔离。
  2. 先脱敏再使用：涉及个人隐私、企业商业秘密、案件当事人等敏感信息，使用前去除实名、证件号、联系方式等可直接定位的字段。
  3. AI 不替代责任与判断：AI 生成的政策表述、数据结论、对外行文，必须由具备权限的人员人工复核、确认、留痕。

一句话守则：能公开的，脱敏后用；涉密的，物理隔离；AI 出的，人复核。

提示词公式：好提示词 = 角色 + 任务 + 材料 + 格式 + 约束。例：「你是一位县政府办文秘，请把以下调研稿改成 800 字政务信息，材料如下……输出三段式、段首小标题；注意用语正式、不编造数据。」

提示词模板库

可直接复制的政务办公提示词

模板按「角色 + 任务 + 材料 + 格式 + 约束」设计，替换【】占位即可，拿走即用、不用懂 prompt 工程。使用前材料先去除实名。

纪要整理

通用五式
把以下会议内容整理成纪要，按「结论 / 待办 / 责任人 / 时限」四栏用表格输出，语言正式、不遗漏关键数字。

长文提炼

通用五式
用 1 页纸概括以下文件：①核心内容 ②与本单位相关的条款 ③下一步建议动作。分三点输出，每条不超过 80 字。

公文初稿

通用五式
以【单位全称】名义起草一份关于【事项】的【通知/函/报告】，包含：背景、具体要求、完成时限。正式公务用语，结构清晰。

数据说明

通用五式
分析以下表格，指出：①异常项 ②可能原因 ③处置建议。用要点列出，不确定处标明"需核实"。

大白话改写

通用五式
把以下政策条文改写成办事群众能看懂的说明，约 200 字，不用专业术语，可举例。

督办台账

办公室
把以下工作部署整理成督办台账表格：事项 / 牵头部门 / 责任人 / 时限 / 当前进度 / 预警等级。进度缺失的标"待更新"。

产业研究

招商
基于以下信息，梳理【某地】的产业链：上游/中游/下游环节、代表企业、招商缺口与建议。用结构化清单输出。

合同审查

司法 / 法制
审查以下合同条款，列出：①风险点 ②对应的法律/合规依据 ③修改建议。不确定处标注"建议律师复核"。

群众诉求归类

人社 / 民政
把以下群众诉求按主题归类（如：社保、就业、救助），每类给出高频问题与统一答复口径。

完整提示词库在 GitHub 仓库 持续扩充，也欢迎提交你的好提示词。

常见问题

关于政务知识库，你可能想问

政务 WorkBuddy 知识库是什么？面向谁？

面向全国公务员的 WorkBuddy 上手与应用开源知识库（发起人陈露 @ActionThinker）：给 AI 小白照着做就能上手，给各部门按职能找到自己的应用场景，给所有人既能用、也能贡献案例，形成裂变。

这个知识库和 WorkBuddyLink 是什么关系？

知识库是公共开源项目，与任何商业实体无绑定；本展示页由 WorkBuddyLink 站点托管展示，并提供政务 AI 培训邀约入口。知识库内容免费开源，培训为可选服务。

公务员用 AI 提效，怎么 0→1 上手？

三步：先读合规红线；再三分钟上手（打开 WorkBuddy → 说人话 → 给材料 → 拿初稿 → 人工核对）；最后找到所在部门的场景卡照着做。提示词公式：角色 + 任务 + 材料 + 格式 + 约束。

政务场景用 AI 有哪些合规红线？

三条绝对红线：涉密材料一律不上传公有云 AI（物理隔离）；先脱敏再使用（去除实名、证件号、联系方式等）；AI 不替代责任（政策表述、数据结论、对外行文必须人工复核留痕）。一句话守则：能公开的，脱敏后用；涉密的，物理隔离；AI 出的，人复核。

我的部门没有对应场景卡怎么办？

先用通用五式提示词跑通常用任务（纪要整理、长文提炼、公文初稿、数据说明、大白话改写）；再按模板提交一张场景卡（Fork 仓库 → 提 Pull Request），帮助全国同行。

知识库里的提示词可以直接复制使用吗？

可以。模板按「角色 + 任务 + 材料 + 格式 + 约束」设计，替换【】占位即可；使用前材料先去除实名，AI 产出须人工复核。

知识库的成效数据可信吗？

成效为示例数据、可核验，尽量量化；无法量化的会注明。请以你自己的实际使用结果为准。

知识库是免费的吗？可以商用吗？

免费开源。内容采用 CC BY-SA 4.0（署名 + 相同方式共享），引用请署名「陈露 @ActionThinker 发起」；Skill / 智能体源码采用 MIT 协议。

知识库怎么持续更新？我能参与共建吗？

通过 GitHub PR 投稿（场景卡 / 案例 / 提示词），维护者按「不涉密、可复现、不夸大、格式规范」审核。本展示页每月同步一次，合规红线变更 24 小时内紧急同步。

知识库和政务 AI 培训是什么关系？

互补关系：知识库适合免费自学起步；需要集中培训、现场陪跑时，可了解 WorkBuddyLink 政务数字办公应用培训，由 WorkBuddyLink 生态专家团队交付，已为政府各级部门开展多次百人规模履职提效 AI 专项培训。

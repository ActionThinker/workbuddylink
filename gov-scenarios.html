使用场景卡之前，请先读这三条红线 强制首读
  1. 涉密材料一律不上传：标注「秘密 / 机密 / 绝密」及内部定为涉密的文件数据，绝不输入任何公有云 AI 工具，物理隔离。
  2. 先脱敏再使用：涉及个人隐私、企业商业秘密、案件当事人等敏感信息，使用前去除实名、证件号、联系方式等可直接定位的字段。
  3. AI 不替代责任与判断：AI 生成的政策表述、数据结论、对外行文，必须由具备权限的人员人工复核、确认、留痕。

一句话守则：能公开的，脱敏后用；涉密的，物理隔离；AI 出的，人复核。

种子场景卡

3 张种子场景卡：照做即可

每张卡 = 一个部门 + 一个场景 + 一套照做步骤（输入 / 提示词 / 产出）+ 量化成效。使用前先读合规红线。

办公室 / 综合协调 · 会议纪要与公文

种子场景卡 难度 ★

部门：办公室 / 综合协调 ｜ 类型：公文与会议 ｜ 使用前请阅读合规红线。

痛点

  • 会议纪要靠人工听写，1 小时会要半天才整理完，还容易漏。
  • 通知、函、汇报材料每次从头写，格式不统一、耗时长。
  • 督办事项散在微信/Excel，进度难跟踪。

任务 A：会议纪要做表（照做）

输入：会议录音转写文本（脱敏后）或手写要点。

把以下会议内容整理成纪要，按「结论 / 待办 / 责任人 / 时限」四栏用表格输出，
语言正式、不遗漏关键数字；无法确认处标"待核实"。

产出：结构化纪要表格，5 分钟内成稿，人工补正即可印发。

任务 B：通知初稿

提示词：

以【单位全称】名义起草一份关于【事项】的通知，含：背景、具体要求、完成时限、报送方式。
正式公务用语，分条列项。

产出：通知初稿，人工核改后下发。

任务 C：督办台账

提示词：

把以下工作部署整理成督办台账表格：事项 / 牵头部门 / 责任人 / 时限 / 当前进度 / 预警等级。
进度缺失的标"待更新"。

产出：可导入 Excel 的督办表。

成效（示例，可核验）

  • 纪要整理：约 70% 时间节省。
  • 常规通知：初稿从 30 分钟降至 5 分钟。
  • 督办：从散落沟通转为一张可跟踪表。

可复用资产

提示词：提示词模板库 · 纪要/督办；模板：可保存为本单位「纪要四栏模板」「通知模板」。

发起：陈露 @ActionThinker（示例脱敏，地区：某区）

延伸场景 · 发改 / 规划：同上能力可迁移——把 50 页政策文件用「长文提炼」提示词浓缩为 1 页要点；把可研报告改为汇报口径；把多项指标做成图表。结构一致，替换材料即可。

招商 / 商务 · 产业研究与对接

种子场景卡 难度 ★★

部门：招商局 / 商务局 / 园区 ｜ 类型：产业研究与对接 ｜ 企业信息须脱敏、以公开资料为准。

痛点

  • 一次招商调研要翻几十个网页，整理产业链、企业、政策，周期长。
  • 对接不同企业，推介材料每次重写，难个性化。
  • 谈判/拜访前难快速形成「这家企业是谁、要什么」的画像。

任务 A：产业链梳理（照做）

输入：目标产业名称（如：动力电池）、本地区位/资源（脱敏描述）。

基于公开信息，梳理【某产业】在【某地区】的产业链：上游/中游/下游环节、代表环节、
招商缺口与补链建议。用结构化清单输出，标注"需核实"项。

产出：产业链地图草稿，作为招商图谱基础。

任务 B：企业画像

输入：目标企业公开信息（官网、年报摘要、公开新闻）。

提示词：

根据以下公开资料，生成该企业画像：主营业务 / 核心竞争力 / 可能的扩产或布局需求 /
与我方招商方向的契合点 / 对接建议。不确定的标"需核实"，不编造数据。

产出：拜访前 1 页纸画像，提升对接针对性。

任务 C：定制化推介材料

提示词：

为【某产业】目标企业起草一页推介：我方区位优势、政策礼包、要素成本、配套。
正式且有说服力，结尾给下一步行动建议。

产出：可复用的推介初稿，按企业微调即可。

成效（示例，可核验）

  • 单项目调研周期：从数天压缩至半天级（初稿+人工核实）。
  • 推介材料：从重复撰写变为「模板+微调」。

可复用资产

提示词：提示词模板库 · 产业研究；模板：产业链梳理模板、企业画像模板、推介材料模板。

发起：陈露 @ActionThinker（示例脱敏，地区：某地）

注意：企业数据须以公开渠道为准，AI 生成仅作草稿，关键事实人工核实后使用。

司法 / 法制 · 审查与普法

种子场景卡 难度 ★★

部门：司法局 / 法制科 / 执法部门 ｜ 类型：审查与普法 ｜ 涉及具体法律意见须由持证人员复核。

痛点

  • 合同/协议条款多，人工逐条审，易漏风险点。
  • 普法材料专业术语多，群众看不懂。
  • 执法依据分散，检索费时。

任务 A：合同条款风险审查（照做）

输入：合同文本（脱敏，去当事人实名）。

审查以下合同条款，列出：①风险点 ②对应的法律/合规依据（注明常见法规，如《民法典》相关编章）③修改建议。
不确定处标注"建议律师复核"，不编造条文。

产出：风险清单 + 修改建议，作为人工复核底稿。

任务 B：普法图文

提示词：

把以下法律要点改写成群众易懂的普法短文，约 300 字，配 3 个生活化例子，不用生僻术语。

产出：可发公众号/社区的普法稿。

任务 C：执法依据检索摘要

提示词：

针对【某执法场景】，梳理适用的法律依据要点、程序要求、常见注意事项。列要点，注明"以最新法规为准"。

产出：执法参考卡（草稿，须核对现行有效法规）。

成效（示例，可核验）

  • 审查：风险点初筛效率提升，人工聚焦关键条款。
  • 普法：材料可读性显著提升，群众反馈改善。

可复用资产

提示词：提示词模板库 · 合同审查；模板：合同审查清单、普法短文模板。

发起：陈露 @ActionThinker（示例脱敏，地区：某地）

重要：AI 审查为辅助底稿，不构成法律意见；正式法律意见须由具备资质人员出具并留痕。

常见问题

关于场景矩阵，你可能想问

政务场景矩阵覆盖哪些部门？

办公室/综合协调、发改/规划、财政/审计、人社/民政、招商/商务、司法/法制、应急管理、政务服务/大数据、宣传/网信、纪检/巡察等 10+ 业务部门，持续扩充中。

场景卡是什么？包含哪些字段？

场景卡是「一个部门 + 一个场景 + 一套照做步骤」的最小单元，字段包括：部门、痛点、做法（输入 + 提示词 + 产出）、成效、可复用资产、贡献者与地区。

场景卡怎么用？

找到所在部门 → 打开场景卡 → 复制提示词 → 替换成你的材料 → 拿到初稿后人工核对。使用前先读合规红线。

我的部门还没有场景卡怎么办？

先用通用五式提示词跑通常用任务（纪要整理、长文提炼、公文初稿、数据说明、大白话改写）；再按模板提交一张新场景卡，帮助全国同行。

种子场景卡和其他部门条目有什么区别？

3 张种子卡（办公室/招商/司法）已完整沉淀：含痛点、做法、提示词、量化成效与可复用资产，照做即可；其余部门为矩阵总览条目，场景卡持续征集补充。

场景卡的成效数据是怎么来的？

成效为示例数据、可核验，尽量量化；无法量化的会注明。请以你自己的实际使用结果为准。

用场景卡要注意什么合规要求？

三条红线：涉密材料一律不上传、先脱敏再使用、AI 产出必须人工复核。司法类场景卡内容为辅助底稿，不构成法律意见。

怎么提交一张新场景卡？

Fork 仓库 → 新建分支 → 按 cases/template.md 填写 → 提 Pull Request。审核四项：不涉密、可复现、不夸大、格式规范。

场景矩阵多久更新一次？

GitHub 仓库实时更新；本展示页每月第一个工作日同步，合规红线变更 24 小时内紧急同步。
